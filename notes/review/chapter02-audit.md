## 旧稿问题与处理

- 旧稿几乎只有定义速记，缺少从问题到机制的解释。新增各节学习目的、为何采用某技术、符号与单位说明、边界及逐步例。
- 波特率/比特率直到2.7才讲，容量却在2.4使用。移到2.2，用4种状态对应00/01/10/11引出log2与一般关系，再用16状态计算及反算例。
- 双工只列名称，串行/并行完全缺失。补两组分类回答不同问题，以及串行全双工仍成立、全双工不必两根网线的解释。
- 异步/同步仅一句话。补时钟漂移、取样、起始位、停止位、字符内仍要同步与8/10效率。
- PCM未展示输出、误差或速率。按课件图分采样/量化/编码；解释3.2→3→011，补采样条件与64kb/s自拟例，不将数字化码率当成模拟信道容量。
- 容量式条件粗略，噪声只写加性；改为课件/教材理想低通无码间串扰模型与带限AWGN模型，介绍功率比、任意低错误率理论含义、共同上界而非实际可达承诺。
- CDM直接给内积公式，初学者无法计算。补码片与信息位的区别、正负映射、内积定义、正交消去机制和4码片平衡码逐项计算。
- 线路编码缺单极/双极区别、初始状态与逐位方法。补NRZ/RZ两张对照、AMI逐次反转、Manchester与差分Manchester的10110手算表。
- 载波/相位/IQ没有入门解释。补频率与相位区分、半周期相位反转、ASK/FSK/PSK波形及DPSK101例、星座横纵轴、点数计数和接收判决。
- 设备段突然引入冲突域/广播域。先讲再生、再给简短域定义并指向第3章；以4用户共享10Mb/s例区别总容量与端口能力。

## 课件和参考书的过度简化、歧义与修正理由

| 来源 | 原表述可能造成的理解 | 本稿处理及理由 |
|---|---|---|
| 课件p20 | 扩频通过“制造干扰”使通信不易被窃听 | 改为展开频带、接收端按约定序列处理，补抗窄带干扰/频带共享；扩频不等同加密，不能保证保密 |
| 课件p23 | 同轴主要频带→同轴只能频带 | 用教材p53／42的50Ω基带/75Ω宽带例补全，介质结构与传输技术不是同一分类 |
| 课件p30、31及旧稿 | 奈氏式适用于所有无噪声通道，香农式任意加性噪声；无差错是逐比特保证 | 显式限定课内低通模型、AWGN平均功率模型；香农可靠性用可把错误概率降得任意小解释，非设备吞吐量保证 |
| 教材p44–45／33–34及旧稿 | RZ一概有自同步信息 | 区分单极RZ的长0不跳变和双极RZ每位脉冲回零；编码名称不足以保证任意数据的同步 |
| 课件p52 vs教材p44／33 | 普通差分码与NRZI及差分Manchester统一跳变含义 | 保留课件普通差分跳变=1；明确教材常见NRZI起始跳变=0；Manchester差分还含固定中点跳变。约定须先读题，不能套一个规则 |
| 课件p57 | 4B5B除16数据码之外另16个都是禁用码 | 余码分控制、保留和无效用途；无效组可提示错，但非数据码不全是错；100BASE-TX/FX例不推成所有快速以太网 |
| 课件p68、p71 | 2PSK始终误码最低、QAM绝对抗噪强 | 保留课件典型比较结论并补能量/接收/信道条件；相同平均功率下高阶星座通常更密，不能无条件排名 |
| 课件p71与旧图注 | 三张星座都称QAM | 明确左方形16QAM、中圆形16QAM、右16PSK作为对照；点数相同不表示幅相结构相同 |
| 课件p30例 vs方形QAM图 | 所有16QAM都恰好4个极角×4幅度 | 题设明确给了4相位每相位4幅度，依题数16；方形QAM按I/Q各4电平计数，不能把两种计数图景混成普遍几何结论 |
| 教材p54／43 | 单模“几乎无反射”定义为光直行；多模只是损耗大 | 正文解释传播模式、到达时间差与脉冲展宽，用全反射作几何直觉；单模不以从不受波导约束定义 |
| 课件p73及旧稿 | 再生等于简单放大，Hub各端口有独立速率 | 补波形/时序恢复与误判边界、Hub共享半双工通路、平均份额；不把再生视为可靠纠错 |

以上针对来源的歧义说明是笔记者整理与必要补充，不声称课件原页提供了全部条件。教材第2章没有按本课八节排列：保留课件结构，仅用于概念核对，不因参考书目录重排课堂主线。

## 整合时补足的采样边界

正文采用严格条件 `f_s > 2 f_max`，解释混叠与重建，并说明教材“不低于两倍”的简写在等号处需要额外限制；采样定理也不能消除量化误差。64 kb/s自拟例改为最高3 kHz、8 kHz采样、256级，以避开原4 kHz/8 kHz的临界相位问题，码率计算保持不变。
